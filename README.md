# AAB visualizer

Kort over dine placeringer på AAB's venteliste. Bygges lokalt ud fra din egen
"Mine boligønsker"-side; repoet indeholder ingen persondata.

1. Gem "Mine boligønsker" fra AAB's selvbetjening som `placeringer.html` i denne mappe.
2. Kør `./build.sh` (kræver [uv](https://docs.astral.sh/uv/)).
3. Åbn `kort.html`.

Detaljer i [tools/README.md](tools/README.md).
